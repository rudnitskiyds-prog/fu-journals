# Журналы Финуниверситета

Статичный сайт со списком журналов, рекомендованных Финансовым университетом (редакция с 01.04.2026, 770 изданий), и данными по каждому: уровень ЕГПНИ («Белый список»), ВАК (К1/К2/К3 и специальности), квартиль Scopus, WoS, ядро РИНЦ (RSCI), РИНЦ, контакты редакции, стоимость и срок публикации, порядок подачи.

## Как устроено

```
data/fu_list.txt     список журналов ФУ (из docx); новая редакция списка — заменить этот файл
data/manual.csv      ручные правки: ISSN, категория ВАК, квартиль WoS, контакты, цена, срок…
data/vak.csv         категории ВАК и специальности (необязательно, см. ниже)
scripts/build.py     сборщик: скачивает источники, сопоставляет, пишет site/data/
site/                сам сайт (index.html, app.js, style.css, data/journals.js|json)
```

Сайт открывается и просто двойным кликом по `site/index.html` — данные лежат в `site/data/journals.js`.

## Ежемесячное обновление

Вручную:

```bash
python3 scripts/build.py
```

Полный прогон занимает 20–40 минут (обход ~800 сайтов журналов). Ответы кэшируются на 25 дней в `data/cache/`, `--fresh` игнорирует кэш, `--no-crawl` пропускает сайты журналов.

Автоматически: `.github/workflows/update.yml` запускается 3-го числа каждого месяца (сборка на GitHub идёт ~45 минут), коммитит данные и публикует `site/` на https://rudnitskiyds-prog.github.io/fu-journals/. Ручной запуск: вкладка Actions → «Ежемесячное обновление» → Run workflow. Правки в `site/` публикуются сразу после push.

Если сайт журнала не ответил (часть российских сайтов закрыта для зарубежных серверов GitHub), контакты и сведения о цене сохраняются из прошлого выпуска с пометкой даты. Каждый прогон сравнивает данные с прошлым выпуском и пишет изменения (уровень ЕГПНИ, квартиль Scopus, ВАК, индексация) во вкладку «Изменения».

## Источники

| Поле | Откуда |
|---|---|
| Уровень ЕГПНИ, WoS CC, Scopus, RSCI, отметка ВАК, издатель | journalrank.rcsi.science (открытая выгрузка JSON + карточки) |
| Квартиль Scopus | SJR из карточки журнала в ЕГПНИ, лучший за последний год |
| Квартиль WoS | только вручную (`manual.csv`, колонка `wos_quartile`) — JCR платный |
| Категория ВАК и специальности | `data/vak.csv` или `manual.csv` |
| Сайт, APC, срок публикации | DOAJ, OpenAlex, Crossref |
| E-mail, телефон, упоминания цены/сроков | автоматически со страниц сайта журнала |

### Категории ВАК

Сайт ВАК не отдаёт перечень в машиночитаемом виде. Скачайте актуальный файл категорирования (К1/К2/К3), сохраните как `data/vak.csv` в формате `data/vak.csv.example` (разделитель `;`, кодировка UTF-8) и перезапустите сборку.

### Ручные правки

`data/manual.csv` (разделитель `;`): любая заполненная ячейка перекрывает автоматические данные. Колонки: `name` (точно как в `fu_list.txt`), `issn`, `vak_category`, `vak_specialties`, `wos_quartile`, `rinc` (да/нет), `site`, `email`, `phone`, `how_to_submit`, `price`, `term`, `notes`. На сайте такие сведения помечены «проверено».
